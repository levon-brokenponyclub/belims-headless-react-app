# Account dashboard mockups

Open [index.html](index.html) to compare the three self-contained concepts. Each mockup uses anonymised fixture values mirrored from `data.json`, Tailwind’s browser CDN, inline CSS, and vanilla JavaScript only. Prototype buttons update only local presentation; they make no network calls and do not change account data.

- `variant-a.html` — Industrial Command Centre: compact operational order workspace.
- `variant-b.html` — Modern Retail Customer Hub: spacious next-action retail experience.
- `variant-c.html` — Hybrid Trade & Retail: balanced recommended direction.
- `components.html` — reusable visual-state reference.

Review at 375, 390, 768, 1024, 1280, and 1536px. The current audit was source- and local-route-response-backed; visual browser/console checks must be completed in a browser during design review.
