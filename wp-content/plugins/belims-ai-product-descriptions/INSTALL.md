# Quick Installation Guide

## Steps to Get Started (5 minutes)

### 1. Activate the Plugin ✅

```bash
# Navigate to WordPress admin
http://your-site.com/wp-admin/plugins.php
```

Find "Belims AI Product Descriptions" and click **Activate**

### 2. Get Your API Key 🔑

1. Go to: https://aistudio.google.com/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key (starts with `AIza...`)

### 3. Configure Settings ⚙️

1. Go to: **Settings → AI Descriptions**
2. Paste your API key
3. Click **Save Settings**

### 4. Test It Out 🚀

1. Go to: **Products → Add New** (or edit existing product)
2. Find the **"AI Product Description Generator"** box in the sidebar
3. Click **"Generate AI Description"**
4. Review the generated description
5. Click **"Apply to Product"**
6. Save the product

## That's It! 🎉

You're now ready to generate AI-powered product descriptions for all your WooCommerce products.
