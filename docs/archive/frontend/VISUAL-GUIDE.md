## Component Size Reference

### Desktop (1440px)

```
Header:               Full width, 128px total height
Hero:                 Full width, ~400px height
CategoryStrip:        Full width, 6 columns
CategorySlider:       Full width, products ~260px wide
DealsHero:            Full width, 3 columns
WeeklyDeals:          Full width, 4 columns
TradeEssentials:      Full width, 5 columns
BrandStrip:           Full width, 6 columns
Spotlights:           Full width, 3 columns, 300px+ height each
Projects:             Full width, 4 columns
Lifestyle:            Full width, 2 columns
Seasonal:             Full width, 3 columns
SEOCategories:        Full width, single list
Footer:               Full width, 4 columns
```

### Tablet (768px)

```
Header:               Full width (responsive)
Hero:                 2 columns collapse to 1
CategoryStrip:        6 → 3 columns
CategorySlider:       Products same width, scroll continues
DealsHero:            3 → 2 columns
WeeklyDeals:          4 → 2 columns
TradeEssentials:      5 → 3 columns
BrandStrip:           6 → 3 columns
Spotlights:           3 → 2 columns
Projects:             4 → 2 columns
Lifestyle:            2 → 1 column (stacked)
Seasonal:             3 → 2 columns
Footer:               4 → 2 columns
```

### Mobile (360px)

```
Header:               Full width (hamburger menu recommended)
Hero:                 1 column, full width
CategoryStrip:        6 → 2 columns
CategorySlider:       Single column, horizontal scroll
DealsHero:            3 → 1 column
WeeklyDeals:          4 → 1 column
TradeEssentials:      5 → 1 column
BrandStrip:           6 → 2 columns
Spotlights:           3 → 1 column
Projects:             4 → 1 column
Lifestyle:            1 column, full width
Seasonal:             3 → 1 column
SEOCategories:        Single list (full width)
Footer:               4 → 1 column
```
