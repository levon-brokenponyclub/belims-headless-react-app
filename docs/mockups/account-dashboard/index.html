Belims · account redesign

Account dashboard: three options

Same data, three layouts. Use the Mock toggle inside each option (Default / Loading / Empty / Trade). Audit: AUDIT.md.

  • Option A · SELECTED — full account built

    Industrial command centre

    Dark band, left rail, big latest-order tracker, dense orders table.

    Best for
    Repeat trade buyers who live in order status; desktop-first.
    Pros
    Strong 'where is my order?' answer; tracking front and centre; dense table scans fast.
    Cons
    Table is heavy on mobile (becomes stacked rows); most visual change from today.
    Build effort
    Medium
    OpenTradeEmpty

  • Option B

    Clean card dashboard

    No sidebar: tabs under the header, bento cards, wishlist and address on the dashboard.

    Best for
    Retail customers, mobile-first.
    Pros
    Lightest to build; mobile is natural (tabs, one column); calm hierarchy.
    Cons
    Least useful for repeat buying; no reorder emphasis; trade is just a line of text.
    Build effort
    Low–Medium
    OpenTradeEmpty

  • Option C

    Trade / pro dashboard

    Slim rail → bottom tab bar, Buy again grid from real order lines, expandable history with per-item reorder, trade panel.

    Best for
    Contractors and repeat buyers; best fit for a hardware store.
    Pros
    Reorder in one tap; delivery/collect preference; contractor value; best long-term.
    Cons
    Most new work (reorder + buy-again + preference sync); buy-again needs stock lookup.
    Build effort
    High
    OpenTradeEmpty
